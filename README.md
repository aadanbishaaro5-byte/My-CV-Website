# My CV Website

Website 02/40 ee challenge-ka 40 Websites. Mashruucani waa CV online ah oo
HTML iyo CSS lagu dhisay, si loogu soo bandhigo xogta xiriirka, waxbarashada,
xirfadaha, khibradda iyo mashaariicda.

## Faylasha

- `index.html` — bogga CV-ga iyo naqshadda CSS ee ku dhex qoran.

## Sida loo daawado

Fur `index.html` browser-kaaga si aad u aragto website-ka.

## Xogtaada ku buuxi

Ka hor intaadan website-ka la wadaagin, ku beddel qoraallada tilmaamaha ah
xogtaada saxda ah, sida email-ka, telefoonka, goobta, waxbarashada, heerka
luqadaha iyo link-yada mashaariicda.

Mashruucan kuma jiro JavaScript.
